# تحديث منطقة التحكم — Joystick / D-Pad

- في الوضع الطولي، لا تتغير مساحة لوحة اللعب المعتادة عند وجود مساحة كافية: تحجز الشاشة شريط النقاط، ثم لوحة اللعب المربعة، وتخصص **كامل الارتفاع المتبقي** لمنطقة التحكم. على الشاشات القصيرة فقط تُصغّر اللوحة لاستيعاب الحد الأدنى المطلوب للتحكم.
- عصا التحكم العائمة تظهر في مكان اللمس داخل منطقة التحكم الموسعة، مع إبقاء حلقة العصا ضمن حدود المنطقة حتى عند لمس الأطراف. لا يتغير قياس الحاوية عند بدء اللمس، ولا يُعاد استخدام `WindowInsets.safeGestures` أو `WindowInsets.navigationBars`.
- ضمن **الإعدادات ← إعدادات اللعب والتخصيص ← التحكم**: اختر **عصا عائمة** أو **أزرار الاتجاهات (D-Pad)**؛ الاختيار محفوظ في DataStore ويعود تلقائيًا بعد إعادة تشغيل التطبيق. العصا العائمة هي الاختيار الافتراضي للمستخدمين الحاليين.
- الوضع الطولي: أزرار الاتجاهات مثبتة في المنتصف أسفل اللوحة. الوضع العرضي: يُستخدم جانب مخصص للتحكم، ويُوسَّط D-Pad داخل هذا الجانب حفاظًا على حجم اللوحة. خيار جهة العصا في الوضع العرضي يظهر عند اختيار العصا العائمة فقط.
- تستجيب الأسهم فور الضغط وتُظهر تغيرًا بصريًا أثناء الضغط، من دون اهتزاز إضافي.
- شريط النقاط صار يوسّط العنوان والرقم رأسيًا، مع سطرين مضغوطين وقصّ محسوب للعناوين الطويلة.
- لم تُعدّل آليات المكافآت والعملات والمتجر والثيمات والحفظ السحابي.

## تحقق بعد نسخ المشروع إلى جهاز Windows

```powershell
.\gradlew.bat :app:compileDebugKotlin
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
```

جرّب الشاشة الطولية على هاتف طويل، ولمس أطراف منطقة التحكم، والتبديل بين طريقتي التحكم بالعربي والإنجليزي، والتدوير للوضع العرضي، ومراجعة عدم حدوث قفزة بصرية عند لمس العصا، ثم إغلاق التطبيق وإعادة فتحه للتأكد من حفظ الإعدادات.
