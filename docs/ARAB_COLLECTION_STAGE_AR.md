# Za Snake — مجموعة عربية (Arab Collection)

## المرحلة
النسخة الأساسية: `ZaSnakeAndroid_Themes_Shop_Expansion_Stage.zip` (توسعة المتجر والثيمات، بعد Visual Polish وإصلاح RTL).

## متجر أشكال الثعبان
تحت أشكال الثعبان الحالية تظهر مجموعة عربية جديدة بعنوان **مجموعة عربية / Arab Collection**:

| السكن | السعر (عملات) | الهوية الفنية |
| --- | ---: | --- |
| مصر / Egypt | 180 | أحمر، عاجي، أسود، ولمسة ذهبية |
| الإمارات / UAE | 180 | أخضر زمردي، أبيض، فحمي، ولمسة حمراء |
| الأردن / Jordan | 180 | رأس قرمزي وشرائط داكنة وفاتحة وخضراء |
| فلسطين / Palestine | 180 | رأس داكن مع زيتوني وعاجي وقرمزي |
| الكويت / Kuwait | 180 | فحمي وأخضر وأحمر وعاجي |
| السعودية — مستوحى / Saudi-inspired | 180 | أخضر فاخر وأبيض ولمسة ذهبية، بدون نصوص أو رموز العلم |

المجموعة **6 سكنات × 180 = 1080 عملة** (كل سكن مستقل). الأشكال القديمة Cyber / Ice / Fire تحتفظ بأسعارها 120 / 180 / 250 عملة.

## سياسة ملكية مصر (Grandfathering)
- اللعبة لم تُنشر بعد، والنسخة السابقة كانت تمنح سكن مصر مجانًا تلقائيًا.
- **التثبيت الجديد** للمرحلة الحالية لا يمنح مصر ضمن الأشكال المجانية الثلاثة (Green / Purple / Yellow).
- **التثبيت القديم** الذي عنده مصر ضمن إعدادات `owned_skins` أو كان مختارًا بالفعل يحتفظ بملكيته من غير دفع أو خصم.
- عند بدء النسخة الجديدة، تُنقل ملكية السكنات المدفوعة الموروثة إلى `unlockedSkins` داخل إحصائيات اللاعب؛ حتى تنتقل مع دمج الحفظ السحابي.
- لو حُذفت بيانات التطبيق القديمة بالكامل قبل تجربة النسخة الجديدة، لا يمكن الاستدلال على ملكية مصر القديمة من ذلك الجهاز وحده. لذلك جرّب التحديث فوق النسخة المثبتة أولًا واحتفظ بنسخة احتياطية من بيانات الاختبار.

## الشراء والحفظ
- الأسعار تُحدد في `SnakeSkin.priceCoins` داخل `GameModels.kt`، لا في زر الواجهة.
- كل شراء له معرف ثابت `shop_skin_<key>` داخل `coinSpending`.
- يتم استعادة الملكية من `unlockedSkins` أو من سجل الشراء نفسه عند مزامنة جهازين.
- شراء السكن نفسه مرتين أو دمج نفس المعاملة لا يخصم العملات مرة ثانية.
- السكن يُجهز مباشرة بعد الشراء، ويمكن اختياره لاحقًا من إعدادات المظهر.


## اختبار الموبايل
1. ثبّت التحديث فوق النسخة الحالية بدون مسح بيانات التطبيق. تأكد أن **مصر** ما زالت مملوكة مجانًا، لو كانت ضمن نسختك السابقة.
2. افتح **المتجر ← أشكال الثعبان** وتحقق من العنوان **مجموعة عربية** ومعاينة الستة، والسعر 180 لكل واحد غير مملوك.
3. اشترِ سكنًا بعد تجميع الرصيد المناسب، واختبر تغيّر الرأس والجسم داخل اللعب وفي معاينة المتجر.
4. أغلق اللعبة وافتحها مجددًا، وجرّب اختيار السكن من إعدادات المظهر.
5. كرر محاولة الشراء أو فعّل المزامنة وتأكد من عدم خصم نفس السكن مرتين.
6. في **تثبيت نظيف منفصل**، تأكد أن مصر مدفوعة، وأن الأشكال الثلاثة المجانية ما زالت مجانية.
7. جرّب العربية والإنجليزية، والوضعين الطولي والعرضي، والـD-Pad (الأسهم لا تنعكس مع العربية)، والثيمات الثمانية.
