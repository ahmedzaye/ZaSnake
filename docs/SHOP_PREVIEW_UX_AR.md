# معاينة المتجر وتجربة الاستخدام

- معاينة مرسومة فعليًا لكل شكل ثعبان باستخدام ألوان الجلد نفسه، بدل الاعتماد على إيموجي.
- بطاقة معاينة كبيرة أعلى المتجر، ومعاينة مصغرة لكل عنصر.
- تحديد العنصر بالضغط على البطاقة أو زر المعاينة.
- تأكيد الشراء قبل الخصم، مع توضيح السعر وأن الشكل سيُجهّز بعد الشراء.
- عرض الرصيد، السعر، حالة الملكية، الشكل المجهّز، والعملات الناقصة عند عدم كفاية الرصيد.
- يمكن تجهيز أي شكل مملوك مباشرة من المتجر.
- ثيمات Night وLight وEmerald تظل مجانية.

## التحقق على Windows

```powershell
.\gradlew.bat :app:compileDebugKotlin
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
```

اختبر معاينة الأشكال الثلاثة بالعربي والإنجليزي، إلغاء تأكيد الشراء، الشراء، تجهيز شكل مملوك، ثم إغلاق التطبيق وفتحه للتأكد من استمرار الرصيد والملكية.
